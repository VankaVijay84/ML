# Box Office Revenue Prediction

## Files
- `Box_Office_Revenue_Prediction_RandomForest_XGBoost.ipynb` — Google Colab notebook
- `box_office_revenue_dataset.csv` — 1,200-row project dataset
- `new_movie_prediction_template.csv` — sample input for a new movie

## Target
`Box_Office_Revenue_Million_USD`

## Models
1. Random Forest Regressor
2. XGBoost Regressor

## How to use
1. Open the `.ipynb` in Google Colab.
2. Upload `box_office_revenue_dataset.csv` when prompted.
3. Run the cells from top to bottom.
4. The notebook trains both models, compares MAE/RMSE/R², plots predictions and feature importance, and predicts revenue for a new movie.

The supplied dataset is synthetic and designed for educational/project demonstration purposes.
